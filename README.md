## Projects

### SimpleBashUtils — s21_cat

A C implementation of the `cat` command-line utility.

**Features:**
- Reading and processing multiple files
- Command-line argument parsing with `getopt_long`
- Line numbering (`-n`, `-b`)
- Squeezing repeated blank lines (`-s`)
- Displaying non-printing characters (`-v`)
- Displaying line endings and tabs (`-E`, `-T`)
- Combined options (`-e`, `-t`, `-A`)

**Technologies:** C, standard C library, POSIX,
command-line utilities.
